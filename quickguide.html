"symbols" by Flōyél — Quickguide

Welcome.txt

This is the full guide to the Flōyél Hub — a program that gathers the Library, Territories, and Maps into one place on your computer, with a small terminal for quick direct access to everything.

You don't need to know anything about Python or terminals to use this. Every command you'll ever need to type is shown below in a copy-paste box — click Copy, then paste it in.

 Getting Started

Two different "terminals" get mentioned in this guide, and they are not the same thing:

  • Your computer's terminal — a program on your Mac/Windows/Linux machine (Terminal, Command Prompt, PowerShell). You use this once, to install a couple of things and start the Hub.
  • The Hub's own terminal — a small window inside the Hub itself, for typing quick commands like open 0001. Nothing you type there touches your computer's real terminal.

This section is about the first one. Pick your system:

Mac
Windows
Linux

1. Open a terminal

Open Terminal (search for it with Spotlight — Cmd+Space, type "Terminal").

Open Command Prompt or PowerShell (search "cmd" or "PowerShell" in the Start menu).

Open your terminal application (varies by distro — usually in your applications menu).

2. Check Python is installed

python3 --version
python --version
python3 --version

If you see a version number, you're set. If not, get Python from python.org/downloads — on Windows, tick "Add python.exe to PATH" during install, this step is easy to miss.

3. Install the two things the Hub needs

pip3 install pywebview flask
pip install pywebview flask
pip3 install pywebview flask
You do not need to install ngrok yourself — the Hub downloads it automatically, only if and when you first open Territories.

4. Move into the folder and start the Hub

In your terminal, type cd (with a trailing space), then drag the System Folder from a Finder/Explorer window straight into the terminal — it fills in the path for you. Press Enter, then run:

python3 hub.py
python hub.py
python3 hub.py

A small window opens — that's the Hub. Leave the terminal window open in the background; closing it stops the Hub.

 The Hub

The Hub is a small window: a terminal on one side, a taskbar strip along the edge. The taskbar has three icons — Library (triangle), Territories (circle), Maps (square). Click one to open it in its own window; click it again to bring that window back to the front instead of opening a second copy.

Click the compass/Start button in the corner of the taskbar to open the Start menu: Profile, Guide (this document), Misc, and Settings.

 Profile
  • Avatar & name — click the circle to upload a picture, type a name underneath. Both are saved.
  • Wallet — a text field to save a wallet address, plus a Save button. This is a separate, simple saved-address box — it is not the same as connecting your real wallet in the Library (see Buying & Wallet).
  • Favourites — you add these from the terminal with fav <id>, this panel shows and lets you remove them.
  • Trail — every command you've typed this session, in order. Click one to run it again.
  • Terminal themes — save your current colour setup under a name (from Customize), then re-apply or delete it later.
 Settings
  • Customize — everything about how the Hub looks: which side the taskbar docks to, icon colours (and uploading your own icon images), four ready-made colour themes, background/taskbar colours (with an optional gradient), text/accent/border colours, a background image, and font style.
  • Library browser — choose whether Library opens inside the Hub ("Built-in") or in a real browser on your computer. See Buying & Wallet for why this matters.
  • Data & sync — opens the Hub's own settings file directly on your computer, in whatever program your OS uses for that file type.
  • Network — shows whether ngrok (used for phone access to Territories) is currently running.

 Library

Browse all the "symbols" — search, filter, sort, view each one's manifest and (if minted) its chain data. Open it from the Hub's taskbar, or type library in the terminal.

Open Settings → Customize (see Settings) to choose whether Library opens inside the Hub or in a real browser — this choice matters most for buying and wallet connection.

 Buying & Wallet

Connecting your wallet

Library has its own "Connect Wallet" button (top of the window) — this is a real connection to MetaMask or a similar wallet extension. Because of how it works, it only functions when Library is set to open in a real browser (Settings → Library browser → pick your browser), since the built-in mode has no extensions at all.

This is different from the Wallet field in your Profile panel — that one just saves an address for later; it isn't connected to this real wallet flow.

Setting Up Your Wallet

For the full System Folder experience, a browser extension wallet (MetaMask is the most common) is recommended. Mobile wallet apps exist too and work similarly, if you'd rather use your phone.

If you've received a wallet from us with "symbols" already on it: install MetaMask, choose Import an existing wallet during setup, and enter the 12-word seed phrase you were given. Your "symbols" will appear once it's imported.

Important: a seed phrase you didn't generate yourself is not fully private — treat anything on a gifted wallet as visible to whoever gave it to you. Set up your own wallet below and move your "symbol" to it as soon as you can.

Setting Up Your Own Wallet

  1. In MetaMask, choose Create a new wallet instead of importing.
  2. Write down the new seed phrase it gives you, on paper, somewhere private — this is the only copy that matters.
  3. Confirm the seed phrase when asked, and set a password.
  4. Copy your new wallet's address (starts with 0x…).
  5. Switch back to your gifted wallet in MetaMask, open the "symbol" on Basescan, and use its transfer/send function to send it to your new address.
  6. Switch to your new wallet and confirm the "symbol" has arrived.
Never share a seed phrase with anyone, for any reason — not "support," not a giveaway, not a friend. Anyone who has it owns everything in that wallet, permanently, with no way to undo it. Don't type it into a website, a chat, or a screenshot. Write it down on paper and keep that somewhere private.

Buying a pack

Click Buy in the Library to open the guide built into it:

  1. Opens the "symbol" sale contract on Basescan.
  2. Click Connect to Web3, connect your wallet — must be on the Base network.
  3. Make sure you have at least 0.0033 ETH on Base.
  4. Find buyPack in the list, expand it.
  5. In the value field, enter 0.0033, select ETH.
  6. Click Write, confirm in your wallet.
  7. You receive 5 random "symbol" Alpha tokens.
First 5 packs per wallet can be bought back-to-back; after that there's a 24-hour cooldown. "symbols" show as unrevealed on marketplaces until their metadata resolves — that's expected for Alpha.

Updating chain data

Click Update in the Library — it fetches the latest on-chain info directly, no separate program to run. For a full rebuild from scratch, there's also a script:

python3 chain_index.py

(run from inside the library/ folder, in your computer's terminal)

 Territories

Opening Territories

Augmented-reality spaces you visit through your phone's camera. Open from the taskbar, or type territories.

Click Launch on a territory and a QR code appears. Scan it with your phone's camera — it opens that territory on your phone through the Hub, connected over ngrok.

Opening a territory without the Hub

If the territory's files are already on your phone — copied over directly, or hosted on GitHub — you can open its page straight from your phone's browser. This works because each territory is fully self-contained.

 Maps

Click the square icon in the taskbar to see every map that's been added — click one to open it.

 Misc

Whatever's dropped into the misc/ folder shows up automatically in the Misc panel — no setup needed. Currently:

  • HEX5 — Random logic to generate element codes for "symbols".
  • Screensaver — an animated "symbol" screensaver. Note: opens in a browser tab rather than a Hub window
  • Symbol Wheel — a spinning random-draw wheel that picks a "symbol" for you.
  • Lumasynth — an image-to-sound instrument: drop a "symbol" gif in, sculpt it into a tone, print it to a file.
  • Tao Te Ching reader — a text-based reader with multiple translations.
 Adding More Later

Nothing needs registering anywhere — just drop files in the right place and they show up.

  • A new "symbol" — a new folder inside symbols/, named like 0000 - somename, containing its files.
  • A new map — drop the map's .html file directly into maps/maps/.
  • A new territory — a new folder inside territories/ containing a webar-scene.html. Add a territory-data.js alongside it for a full description card; without one, it still shows up with a plain card.
